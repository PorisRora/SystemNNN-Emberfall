# SystemNNN-Emberfall

当前源码版本为 **0.6.5（versionCode 65）**，要求 Android 8.0 及以上、ARM64。独立安装包的默认构建路径为 `build/tyranor/SystemNNN-Emberfall-0.6.5-arm64.apk`。同一签名的版本可覆盖安装并保留各游戏目录的存档。

0.6.5 将阅读字号和 PC 存档按钮悬浮在游戏画面上方，修复打开对应面板时画布偏移。剧情正文字号改为四档，默认 85%。本版沿用 0.6.4 的原生内核代码。宿主接入和存档目录约定见[内置接入说明](tyn/README.md)。

直接打开模块后可点「选择游戏目录」，选择含 `spt/sys.spt` 的完整游戏文件夹；也可以从 TYN 游戏库启动。Windows EXE 可以留在目录中，引擎读取同目录里的脚本和资源。

1. 在已实测的 Tyranor-Next beta-1.63，从首页左边缘向右滑出官方「妙妙工具」，打开「引擎模块管理」，点右上角刷新并启用「SystemNNN-Emberfall」。
2. 在「设置 → 游戏目录添加」添加游戏所在的父目录，再到「游戏」点「扫描游戏」。
3. 点标为 `Plugin` 的游戏卡片，再点「启动游戏」。首次启动按提示允许 SystemNNN 访问游戏文件。
4. 标题页「新的游戏」进入剧情，「继续游戏」读取自动进度，「读取」打开存档列表。标题设置和游戏内环境设置共用参数。停在标题页不会改写剧情存档。

## 菜单、配置与文字

菜单读取所选游戏的原始配置、图包、坐标和按钮音效／语音。《死终Ω神盾》的标题背景由 `DEA_backscript.spt` 驱动，按钮和音乐来自 `init/title.xtx`。游戏内系统菜单映射原版按钮，存读档按游戏配置呈现槽位网格、翻页和覆盖确认。环境设置按游戏配置呈现分类音量及开关、角色语音组、系统语音、文字与 Auto 选项。滑条刻度、松手试听、预览字号和行距读取游戏配置。

箭头分页按原版规则显示可用方向。首页隐藏向上箭头，末页隐藏向下箭头，单页隐藏两枚箭头。使用箭头的设置页和存读档页，以及 CG、回想和动画鉴赏列表使用这套规则。

环境设置页悬浮的「阅读字号」提供 60%、85%、100% 和 115% 四档，只缩放剧情正文及其行距。100% 是原版大小，「恢复默认」切回 85%。设置保存在播放器偏好中，适用于所加载的游戏。剧情和面板始终按完整安全区域等比居中。

剧情按钮由 `game.xtx` 的创建／启用开关，以及 `optionButton`、`quickSaveButton`、`quickLoadButton` 等独立配置共同决定；图片状态、坐标、透明命中区、点击音和点击等待帧数来自相同配置。已测三套数据均只有系统菜单、快存、快读三个按钮；《死终Ω神盾》的系统菜单在右下区域最上方，《鏖殺ノ乙女》在最下方。按钮未配置时不会额外生成顶部 Auto／Skip 操作栏。原版系统菜单提供 Auto、Skip、历史和隐藏入口，末项确认后返回标题；从环境设定、存读档或历史点返回，直接回到剧情。

系统菜单第 10 项起可通过 `optionNumber` 和 `expOptionModeN` 接入原版可选面板，按钮继承原配置的图集、布局和音效，并检查 `game` 中设置的启用变量。从状态或商店等子面板返回时恢复打开菜单前的剧情或选择状态。流程图成功选中节点后按原版规则恢复或继续执行脚本。

首次打开游戏时，按 `logo` 配置展示各张开屏贴图，支持配置的点击跳过。设置、存读档等面板会在配置指定 `backScript` 时执行动态背景。装饰会话拥有独立 VM／画面和模式覆盖，与剧情共享运行参数。标题、鉴赏及系统面板按配置驱动按钮帧、确认等待和进场。系统菜单按 `backScreenType` 使用静态图、剧情画面或背景脚本，并按配置处理捕获画面的灰度及 RGB 偏移。

入场转场使用背景脚本第 0 帧。淡入结束后，菜单等待和展开使用配置的帧时钟，背景按配置限额补算慢帧。每个游戏目录最多保留两套装饰执行状态，共用一个后台线程和 48 MiB 贴图缓存。打开设置或存读档时，可在按钮确认动画期间准备背景。预热使用隔离上下文，打开时检查运行参数和进度，再绑定当前会话。

设置、读档和鉴赏退场后将退出画面传给下一模式。返回标题会从第 0 帧启动标题背景。手动读档先播放槽位确认动画，再恢复快照并交接剧情画面。如果从设置或存读档的填色退场返回选择支，而选择支未配置入场效果，则使用对白的入场过渡。

标题的鉴赏入口读取游戏的 `omake` 配置。CG、回想、音乐和影片按游戏列表显示。大于画布的 CG 按 `printcg` 的方向和时间自动平移，也可拖动。切换差分及返回使用各自音效。音乐鉴赏使用配置的滑条、播放与暂停图集，并用 BGM PCM 计算频谱和峰值。`selectMovie` 提供缩略图、网格及翻页，`printMovie` 决定播放设置和能否跳过。剧情影片和鉴赏共用本地 ASF 与 MPEG 播放器。剧情执行到影片指令时登记鉴赏槽，解锁记录按游戏目录保存。回想依 `scene.dat` 的片段顺序播放，在结束时回到列表。

引擎配置优先读取并解密 `init2/*.fxf`，缺失时读取 `init/*.xtx`。键名忽略大小写，同名字段取首项。`GameTextDecoder` 处理 CP932、`sjis_ext.bin` 字符隧道，以及明确启用的 UIF 字符替换。配置标签、对白和姓名使用同一套游戏文字解码。资源名称保留原始字节。对话窗使用游戏贴图、坐标与逐行 `nextX` 偏移，姓名和正文分别显示，姓名配色读取 `spt/namecol.xtx`／`.fxf`。

姓名文字与姓名窗贴图分别按 `printmessage` 和 `messageWindow` 控制。姓名的锚点、对齐、字距和字体类型覆盖来自 `printmessage`，字重来自 `game`。关闭姓名或使用 LPRINT 时，首行仍可作为正文显示。

本批《死终Ω神盾》汉化安装的配置文本采用旧式每行 59 项隧道，SPT 剧情采用每行 58 项隧道。配置文本通过显式的兼容解码入口处理，正文仍用原来的规则，不根据中文字义猜测或替换。配置文件本身没有编码版本标记；其他汉化工具生成的配置编码仍需核对。

## 运行参数与文字行为

`GameSession` 持有持续运行的脚本、渲染与音频状态。共享的 native `RuntimeContext` 是系统参数、已读身份和实际快进状态的 owner；参数按原 `NNNPARAM` ID 访问，保留配置决定的别名与写入限制，并通过锁保护批量更新。菜单预览借用同一上下文；读档候选先 `fork()` 隔离，成功后才提交，不让失败重放改动当前会话。

初始参数来自安装目录中可识别且版号明确的 `sav/sysfile*.org`／`tsysfile*.org`；没有合适文件时使用原版 `CreateInitData` 默认值，并记录原因。随后只应用该游戏目录下用户明确保存的 raw 参数覆盖。SharedPreferences 负责这些覆盖与显示偏好的持久化，不再用 Java 的固定八项、统一 80% 默认值覆盖 native 初值。旧全局设置不会在单位不明时自动当作新默认值迁入，也不会读取 PC 用户的 `.sav` 当作初始参数。

`PlayerBehavior` 在 native 层按原 `printmessage`／`config` 计算文字 CPS、分帧余数和 Auto 等待。Android 提供解码后的字数并显示 Core 给出的可见字数，点击补全和能否推进也由 Core 决定。Auto 在文字完成后的下一帧开始消耗等待；带语音的句子使用记录的完整语音时长加原配置等待，无语音句子使用相应等待表，静音不改变该身份。不会以「当前是否仍在播放」或正文长度另造推进条件。脚本消息速度覆盖使用原版指定的速度表。

对话文字显示完成后，等待光标按 `messageCursor` 的手动、Auto 和大段文字模式取用原版帧。选择支按 `selectmessage` 绘制窗口、文字与光标，确认时播放配置的 SE。**确认选项后**，Core 按原 `210`／`211` 开关决定是否关闭 Auto／Skip，并按选择序号记录已选状态。限时选择在选项入场后开始计时，按脚本进入超时分支。计时条和数字显示由游戏配置决定。

## 游戏内操作

- 点击对话：未显示完整时先补全文字，再次点击推进；选择肢直接点击对应按钮。点击、打开菜单或隐藏界面会取消自动／快进。普通画面点击和隐藏恢复不额外播放系统按钮音效；实际按钮仍保留按钮音效。
- **Auto**：使用上述 native 文字完成状态与原版等待时序。
- **Skip**：按当前 SkipMode 快进。仅已读模式在新未读台词处由 Core 停止。已读身份使用脚本编号与消息序号，随游戏的 NNR4 全局进度保存，旧记录保留迁移入口。
- **回看（Backlog）**：查看最近 100 条台词及说话人。原生快照恢复保存时的履历，旧档通过原输入记录重建。游戏配置允许跳回时，可以从可用的履历条目恢复剧情。
- **隐藏（Hide）**：隐藏台词与剧情按钮；点击画面或按返回键恢复显示。
- **QSave／QLoad**：覆盖快速槽／读取快速槽，独立于手动存档和自动进度。

菜单打开期间暂停主剧情 VM、图层和文字时钟；独立的菜单背景脚本与音频混音继续运行。弹出层隐藏剧情文字和快捷按钮，返回时恢复。Core 的实际 Auto／Skip 状态回传界面，平台不会每帧用旧缓存重新开启已停止的快进。

转场完成时，渲染器会通知平台提交精确终帧；仅更新缓存却不提交终帧会造成画面停留在双影状态。Android 界面显式处理系统栏和刘海安全区，整个游戏画布在安全区内等比缩放；原版按钮保留游戏内坐标，不另排成 Android 快捷栏。该处理也用于 [Android15 对 target35 的全屏布局要求](https://developer.android.com/about/versions/15/behavior-changes-15#edge-to-edge)。

## 存档与恢复

每个游戏目录有 **20 个手动槽、1 个自动槽、1 个快速槽**，保存在该游戏的 `sav` 文件夹；已有的 `SAV` 等大小写变体会复用。Emberfall 使用固定的 `emberfall` 文件名前缀，与 PC 原版文件分开。快速槽在 `dataFile` 指定的位置绘制专用贴图，手动选择权限由 `save`／`load` 配置决定。箭头翻页，自动槽在最后一页。游玩中切到后台或返回标题会保存有效自动进度。快存与快读使用 `notice` 的提示图和时间设置，空的快速槽显示禁用按钮。

列表显示槽位编号、时间、脚本、句号、说话人和正文摘要。最多 40 字的摘要与输入／Skip 记录存放在同一个带校验的 NS2 原子文件中。场景缩略图单独保存并按保存时间匹配，旧存档仍可读取。`emberfall.sav` 对应手动槽 01，`emberfall.slot01.sav` 至 `emberfall.slot19.sav` 对应手动槽 02–20，`emberfall.resume` 是自动槽，`emberfall.quick.sav` 是快速槽，缩略图追加 `.thumb`。把整个游戏目录连同 `sav` 一起移动后，存档文件名不随绝对路径变化。

首次打开原游戏目录时，播放器会复制当前应用可访问的旧 UUID 私有存档及配套进度，保留旧文件。目标已有存档优先；迁移中断会在再次打开时继续处理，出错时提示且不带着半套进度启动，也不静默改回私有目录。独立 APK 与 TYN 的应用私有目录互不可读，因此从独立版转内置版时，应先用更新后的独立 APK 打开一次原游戏目录。Android 设置偏好仍由各应用自己的 SharedPreferences 保存。

NS2 附带独立校验的压缩原生快照，保存活动 VM、脚本位置、调用栈、变量、图层及转场、剧情音轨、对白时钟和历史。游戏内校验快照后原地恢复，复用贴图、已加载脚本和解码缓存。同一首循环 BGM 保留播放位置。原生快照 v9 加入待确认的角色和对象选择，流程图使用 v10 保存节点、连线和脚本命令位置。旧版快照仍可读取。快照不可用时按可重放的输入日志恢复，限时分支和脚本使用的系统时间有独立记录。

全局进度继续使用 NNR4，保存为 `sav/emberfall.read`。配套 NNE2 扩展 `emberfall.read.ext` 保存姓名、文字替换、术语、语音和流程图解锁，可读旧 NNE1。鉴赏记录为 `emberfall.gallery`；流程图节点档存于 `sav/emberfall.chart/`，也可读取安装目录中的原版 `sav/chartN/slotM.dat`。节点通过校验且退场动画结束后才会提交分支。

输入日志达到容量后，继续用完整原生快照存档。仍可使用有效的回看检查点。此类槽位依赖快照，校验失败会保留当前会话。

读档页悬浮的「读取PC存档」可选择 Windows 原版的剧情 `.sav`，直接恢复到该进度。之后可按需保存到手机槽位。存档页悬浮的「导出PC存档」将当前剧情导出为 Windows 可读取的槽位。两个页面也可长按「返回」打开对应操作。

互通要求游戏与脚本版本匹配，使用原版资源路径。这是剧情状态的格式转换：PC 不会直接读取 `emberfall*.sav` 的 NS2 格式，也不会因此自动同步已读、鉴赏解锁或 Android 设置。将两种格式放在同一个 `sav` 中不会改变这一点。

快存提示和手动存档音效在写盘前触发。槽位摘要和缩略图在进入游戏时预载，保存后更新对应槽位。实际读档时校验完整文件。

历史记录由剧情会话保留最近 100 条，按 `backlog` 的位置、行数和字号绘制。支持原版箭头和触屏滑动，带语音图标的条目可重播。回看、系统菜单及快捷设置和存读档入口暂停剧情音效与语音，返回时重启场景的循环音轨。选择支写入选项标题、选项与确认颜色。跳回权限由 `JumpFlag` 和 `enableAppendJump` 控制。

## 验收范围与构建

0.6.3 按用户要求仅做构建、签名和 APK 校验，未做新的模拟器或手机回归。

0.6.2 在 API 30 ARM64 转译模拟器上验证《獄淫の尖塔》《劣等》和《死终Ω神盾》简繁版的自动播放时间与对话框透明度滑块，覆盖拖动、即时预览、保存和返回剧情后重新打开设置。更早的模拟器验收覆盖《死终Ω神盾》简体版和《鏖殺ノ乙女》的设置、标题读档与影片鉴赏入口，以及《獄淫の尖塔》和《劣等》的 800×600 设置、剧情与手动存读档。实际覆盖以这些样本和场景为限。

在 Windows 的仓库根目录运行 `python platform/android/build_player.py` 重建 APK。默认文件名取自 Android manifest 的版本号。本地调试签名密钥保存在 `%LOCALAPPDATA%/CodexTools/SystemNNN-M/debug-signing/emberfall-debug.p12`。 [构建依赖与环境变量](BUILDING.md)

播放器动态链接 FFmpeg 8.1.3，启用 ASF、MPEG 节目流、WMV3、VC-1、WMA、MPEG-1/2 视频和 MP2。APK 内附许可与构建选项。 [FFmpeg 8.1.3 源码](https://codeload.github.com/FFmpeg/FFmpeg/tar.gz/refs/tags/n8.1.3) · [第三方声明](../../THIRD_PARTY_NOTICES.md)
